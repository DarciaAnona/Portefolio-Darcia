# Portfolio — Darcia Anona Tréal

Site statique responsive fondé sur le CV fourni. Les projets sont décrits sans révéler d'informations confidentielles.

## Publier sur Vercel
1. Créer un dépôt GitHub et y ajouter `index.html` et le dossier `assets`.
2. Dans Vercel, choisir **Add New > Project**, importer le dépôt.
3. Framework Preset : **Other** ; Build Command : laisser vide ; Output Directory : `.`.
4. Déployer.

## À personnaliser avant candidature
- Vérifier l'autorisation de publier le portrait et les descriptions de missions.
- Ajouter des technologies précises **uniquement si elles sont réellement maîtrisées**.
- Ajouter des projets personnels publics et leurs liens GitHub / démo si disponibles.
- Mettre à jour la disponibilité et les coordonnées si nécessaire.
